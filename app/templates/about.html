About

Quality estimation of restaurant reviews using the Yelp Open Dataset.

Academic project Flask demo
Dataset

The models are trained on a large subset of the Yelp Open Dataset, specifically filtered for "Restaurants". To ensure balanced learning, the classes were harmonized and undersampled into a balanced corpus of 1.63 million restaurant reviews.

Total Raw Reviews~6.9 Million
Filtered Restaurants~4.7 Million
Balanced Corpus1,629,279
Official Split70% train / 15% validation / 15% test
Deep Learning Subset25,000 train / 5,000 validation
Models
Model Type Architecture / Input Strength
Logistic Regression Classical ML TF-IDF (50k features) + 8 Numeric Fastest inference, highly interpretable.
SVM (LinearSVC) Classical ML TF-IDF + Numeric (Calibrated) Excellent margin separation.
SGD Classifier Classical ML TF-IDF + Numeric Efficient for large-scale learning.
TextCNN Deep Learning Embedding → Conv1D → MaxPool Extracts local n-gram features efficiently.
FastText Deep Learning Embedding → GlobalAveragePooling1D Fast training and evaluation for text classification.
DistilBERT Transformer Official split-compatible fine-tuning workflow Prepared for fair Transformer comparison.
Quality Classes

Average (Orta)

Good (İyi)

How to Run
1.
Install dependencies: pip install -r requirements.txt
2.
Run notebooks in order: 01_data_preparation.ipynb through 08_bert_model.ipynb
3.
Regenerate features and models after method changes: 04_feature_extraction.ipynb, 05_model_training.ipynb, 06_model_evaluation.ipynb
4.
Start UI: cd app && py app.py
